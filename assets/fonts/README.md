# Server-side PDF fonts

These fonts are bundled only for server-generated commercial quotations.

- `IBMPlexSansSC-Regular.ttf`: IBM Plex Sans SC from the official IBM Plex repository.
- `NotoSans-Regular.ttf`: Noto Sans from the official Noto Fonts repository.
- `NotoSansArabic-Regular.ttf`: Noto Sans Arabic from the official Noto Fonts repository.
- `NotoSansThai-Regular.ttf`: Noto Sans Thai from the official Noto Fonts repository.

All four fonts are distributed under the SIL Open Font License 1.1. The corresponding license texts are included in this directory.
